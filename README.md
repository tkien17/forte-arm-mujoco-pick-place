# MuJoCo robotic arm pick-and-place

The project simulates a Panda arm and a customized Forte arm picking colored
cubes and placing them on matching pads with scripted controllers.

Start with the [project README](robotic-arm-pick-and-place/README.md) for the
folder structure and commands. The [Forte integration guide](robotic-arm-pick-and-place/docs/forte.md)
explains the robot, completed stages, validation, and remaining work.

All application code and assets live in `robotic-arm-pick-and-place/`.
